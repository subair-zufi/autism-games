WebXR exit test

Plain WebXR — no framework, no router, no app code. It does exactly one thing on exit: calls XRSession.end(), the same call the game's Quit button makes.

✓ You are back on the page — the window survived the exit.

Inside VR you do not have to press anything: the session ends itself after 10 seconds. The screen flashes white once per second so you can count it down, and shifts from blue towards green as it goes. Pulling a trigger, or pinching with hand tracking, exits early — but neither is needed, which matters when the headset has no controller awake.
