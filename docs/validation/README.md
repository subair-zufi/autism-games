# Forms and instruments

What each file in this folder is, and which protocol governs it. Print from the `.pdf`
where one exists — it has the Malayalam font embedded, so it renders correctly on a machine
that has none installed. Edit the `.docx`.

| File | What it is | Governed by |
|------|-----------|-------------|
| `vr-session-experience-record.*` | **The user-experience instrument (O6).** Eleven items after every session: three asked of the child, five trainer ratings, three short written answers. Page 2 is the rating guide. Normally completed in the app on the trainer console — this is the paper fallback. | [vr-ux-protocol.md](../vr-ux-protocol.md) |
| `vrnq-rating-sheet.*` | VRNQ: is each of the six games good enough VR software for research use? Rated by the expert panel and facilitators, **not** by the children. The 20 item wordings must be transcribed from the source paper before use. | [vr-ux-protocol.md](../vr-ux-protocol.md) |
| `content-validity-dossier.docx` | The games described for the expert panel, for content validity. | [study-blueprint-buds.md](../study-blueprint-buds.md) §14 phase 0 |
| `expert-cvi-rating-form.docx` | The panel's CVI ratings. | as above |
| `vr-on-device-checklist.docx` | Pre-session headset checks. | [vr-on-device-checklist.md](../vr-on-device-checklist.md) |
| `vr-ux-forms.docx` | **Superseded.** The forms for the five-construct battery the protocol used to specify. Kept for reference only — see the note at the top of the protocol about what was dropped and why. | — |
| `vr-session-ux-form.*` | **Superseded.** An earlier one-page snapshot of a single session. The per-session experience record replaces it: the questions are fixed and repeated, so it can show change across sessions, which this could not. | — |

The two superseded forms are kept rather than deleted so the earlier design stays on the
record — a methods chapter that says what was considered and dropped is stronger than one
that does not. **Do not take either into the field.**

Consent, assent, ISAA and data-request letters are listed in
[study-blueprint-buds.md §16](../study-blueprint-buds.md); add them here as they are
finalised.
